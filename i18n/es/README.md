# Spanish

Status: not started. 0 of 101 prompts translated.

Spanish is the pilot language because it has the largest native-speaking
developer population outside the English- and Chinese-speaking ones, and
because it is the language this repo's readers ask for most often.

## Conventions

Read [../README.md](../README.md) first: it has the layout, the required
structure of a translated file, and why no prompt in this folder will be
machine-translated.

Short version:

- One PR per prompt. Do not translate the category README, and do not translate
  prompts that have not changed upstream.
- Keep the English filename and the same `<category>/` folder, so the mirror
  path stays obvious.
- Translate the title, the usage note, the `Keywords:` line, and the prompt
  body. Leave code, file paths, commands, and identifiers in English.
- Translate the prompt body as instructions to a colleague, not as prose. The
  imperative force matters: if the English says "Never skip the tests", the
  Spanish has to keep the "never", not soften it into "it is better to".
- Paste your translation into a real coding agent and watch what it does before
  opening the PR. A body that reads correctly can still instruct the wrong
  action.
